# Career Gate — Staff Go-Live SOP

Status: Current production SOP  
Production: https://alhijrah-caseflow.vercel.app  
Staff sign-in: https://alhijrah-caseflow.vercel.app/staff/login

## 1. Sign in
- Open **Staff Sign In**.
- Enter the approved work email.
- Complete the 6-digit email OTP.
- Do not share OTPs, sessions, or staff credentials.

## 2. Start Smart Import / Client Intake
- Use the existing **Smart Client Import / Client Intake** workflow.
- Enter only client-provided information.
- Upload only documents provided for that client.
- Do not create a second client path or duplicate record to bypass the workflow.

## 3. Review and approve client data
- Review the extracted/client-entered information.
- Correct only verified client information.
- Confirm document/data matches through the existing review controls.
- Approve only when the record is complete enough for the existing workflow.
- Do not bypass verification, validation, or required review states.

## 4. Open the resulting Client
- Open the Client created/resolved by the approved workflow.
- Confirm the correct client identity, contact information, assignment, application status, and attached documents before continuing work.
- Do not work from a duplicate client record.

## 5. Payment / financial action
- Financial actions are management/admin functions only where authorized by the current role and permissions.
- Record payment, discount, refund, waiver, adjustment, receipt, or commission only through the existing accounting controls.
- Staff must not bypass blocked financial controls or edit database values directly.

## 6. Staff must not
- Change another user's role or permissions.
- Perform admin/accounting actions that the system blocks.
- Hard-delete client/import/accounting records.
- Edit Production directly outside the application workflow.
- Share client data, OTPs, secrets, tokens, or internal credentials.
- Create parallel intake, document, payment, or tracking records.
- Treat test/training data as a real client.

## 7. Escalate a blocker
Stop the affected action and report:
- screen / route,
- client reference if applicable,
- exact error text,
- action attempted,
- time of failure.

Do not retry by creating duplicate records or using a different workflow. Continue unrelated authorized work only when safe.
